Toha generates projects and files from templates. A template contains
`template.yml`, a source directory, and optional support files. Toha asks an
interview, then renders file paths and contents with Jinja.

The [concept](https://github.com/wyrd-company/toha/blob/main/docs/concepts/toha.yml)
defines the intended product. The [template format](https://github.com/wyrd-company/toha/blob/main/docs/specifications/template-format.yml)
defines what a template can contain.
